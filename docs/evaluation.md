# 評估方法與結果

所有評估都是離線、靜態的：不操作鍵盤、不碰輸入法、不開視窗，只用固定的候選清單走程式本身的 `BuildQuestions`、`Refine`、`Propose`，所以測的就是正式的 prompt 與規則。案例在 [tests/JevboardTests.cs](../tests/JevboardTests.cs)。

## 怎麼跑

```bash
powershell -NoProfile -ExecutionPolicy Bypass -File tests\run-tests.ps1          # 單元測試
powershell -NoProfile -ExecutionPolicy Bypass -File tests\run-tests.ps1 -Live    # 單元測試 + 111 句線上評估
powershell -NoProfile -ExecutionPolicy Bypass -File tests\run-tests.ps1 -Whole   # 只跑整句案例，印出實際請求與回答
```

線上評估需要托盤「設定…」裡儲存的 Jev API key；每句約 2–4 次請求，111 句約 5–8 分鐘。

## 評估集（`Cases`，111 句）

每個案例是：一句正確的句子、目標詞、同音錯字、幾個同音候選（近似輸入法第 1 頁）。正確與錯誤用字的注音讀音含聲調相同，否則輸入法不會列出那個候選（哪／那、發／髮、乾／幹 聲調不同，所以沒有收）。

- **8 組同音詞各兩個語境**：魷魚／由於、權利／權力、公事／公式、意義／異議、終於／忠於、期中／其中、技術／計數、近視／進士。
- **實際使用中出錯的句子**：我喜歡你（曾建議懽）、公事公辦（曾建議办）、在再不分（曾被改成部份）。
- **47 句常見同音錯誤**：的／得、在／再、作／做、已／以、須／需、帶／戴、製／制、複／復、練／鍊、歷／曆、訂／定、隻／支、麵／面、進／近、像／象，以及整詞選錯（已經／以經、知道／之道、需要／須要、其實／期實、因為／音為、密碼／蜜碼、下載／下在、遊戲／游戲、藥／要、賣／麥…）。
- **44 句語境決定**：同一組同音字在兩句裡各自正確，只有上下文能分辨：做愛要戴保險套／出門要帶保險套、記得戴帽子／記得帶外套、它該換了／他餓了、三堂課／一顆蘋果、這件事／他是／試試看、像媽媽／向右轉、回覆／恢復／複習、紀念／記得／計畫、經過／精神、爆了／報告、開會／繪畫、問題／提出、買票／漂亮、放鬆／松樹、餅乾／干擾、皇后／之後、見面／吃麵、一座山／請坐、員工／原因／一百元／公園／圓形、項鍊／練習、一億／意義。

每句各跑兩次：

- **錯字起跑**：假設輸入法選了錯字（錯字當 c1），應該改回正確字。
- **正確起跑**：假設輸入法選對了，不該改壞。

另有四句走完整流程（多位置、迭代、成對比較）：

| 案例 | 輸入 | 期望 |
|---|---|---|
| 一句多錯 | 留言妃與 | 流言蜚語 |
| 音譯名＋性別 | 我愛你你是我的羅密歐 | 不改 |
| 相鄰兩錯 | 在是一次 | 再試一次 |
| 兩處獨立錯字 | 想在去一次芮氏 | 想再去一次瑞士 |

## 最新結果（2026-10-03，jev-1.13.0）

| 指標 | 結果 |
|---|---|
| 錯字起跑改對 | 100 / 111 |
| 正確起跑不改壞 | 109 / 111 |
| 完整流程 | 4 / 4 |

改壞的兩句：

- **在再不分 → 在再部分**：這句在談「在」「再」兩個字本身，不是正常句子；Jev 以約 0.85 把「不分」改成「部分」，也不會把第 1 字改成「再」。語言模型靠語意判斷，這類以字為話題的句子分辨不出來，只能靠使用者按 Esc。
- **出門要帶保險套 → 戴**：Jev 對「保險套」有「戴」的搭配偏好，看不出「出門」是攜帶的語境（做愛要戴保險套、記得戴帽子、記得帶外套則都對）。

沒改對的多半是兩邊都說得通或模型分不出的字，會以可選列出現：權利／權力（各約 0.5）、制度／製度、皇后／皇後、一枝／一支玫瑰、它該換了／他、負責計數／技術。「公事公办 → 公事公辦」是評估才有的起跑狀態（輸入法不會把簡體字當轉換結果），門檻加嚴後「辦」約 0.6 只列為可選。

API 每次回答略有浮動，門檻邊緣（約 0.6）的句子有時只列為可選；同一評估集多次執行的改對數在 100 ± 3。

## 歷次演進

| 版本 | 16 句原始集 | 備註 |
|---|---|---|
| state 含原句、選項為單字 | 12/16 改對 | 會建議簡體「由于」 |
| state 只描述情境、選項為整句（現行措辭） | 16/16 改對、15/16 不改壞 | |
| 加門檻（≥ 0.5 且兩倍）、性別字不換 | 15/20 改對、19/20 不改壞 | 擋掉遊於、權利、蘿 |
| 正反序平均、迭代、成對比較、111 句 | 100/111 改對、109/111 不改壞 | 在是一次 ✓、羅密歐 ✓ |
| 前文不再含組字本身 | 不變（評估集沒有前文） | 記事本裡「想在去一次芮氏」的瑞士從 0.44 回到 0.98 |

## 怎麼加案例

在 `Cases` 加一行：

```csharp
C("句子（正確版本）。", "正確詞", "錯字詞", "其他同音候選", "…"),
```

位移由句子自動算出（第一次出現的正確詞）。整句案例在 `RunMulti`，用 `Position` 列出每個位置的候選頁，`Whole(s, 期望句, 標籤)` 會印出每一輪的請求與回答。

## 注意事項

- 評估用的候選清單是依讀音推測的近似值，真實輸入法的第 1 頁可能不同（順序會隨學習改變）。
- 「錯字起跑」裡的錯字有些不會是輸入法的實際轉換結果（例如簡體字），只用來測 prompt 的分辨力。
- 結果反映 jev-latest 當下指向的模型版本；模型更新後請重跑。
